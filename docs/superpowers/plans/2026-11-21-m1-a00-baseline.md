### Task 2: Native CI

**Role:** `worker-simple` (one file, exact content).

**File:** Create `.github/workflows/rust.yml`.

**Interface:** Consumes Task 1's stable toolchain and generated lockfile. Produces the same native checks on both platforms for any branch push (no tags, no duplicate PR-triggered builds). Use this workflow:

```yaml
name: Rust

on:
  push:
    branches: ['**']

permissions:
  contents: read

jobs:
  native:
    name: Rust (${{ matrix.os }})
    runs-on: ${{ matrix.os }}
    timeout-minutes: 15
    strategy:
      fail-fast: false
      matrix:
        include:
          - os: ubuntu-24.04
            host: x86_64-unknown-linux-gnu
          - os: windows-2025
            host: x86_64-pc-windows-msvc
    defaults:
      run:
        shell: bash
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          persist-credentials: false
      - run: rustup toolchain install stable --profile minimal --component rustfmt
      - name: Check native toolchain
        env:
          EXPECTED_HOST: ${{ matrix.host }}
        run: |
          export LC_ALL=C
          rustc_info="$(rustc -Vv | tr -d '\r')"
          printf '%s\n' "$rustc_info"
          grep -Fx "host: $EXPECTED_HOST" <<< "$rustc_info"
          cargo --version
      - run: cargo fmt --all -- --check
      - run: cargo build --workspace --locked
      - run: cargo test --workspace --locked
```
