# Remaining M1 — Working Core Implementation Plan

> **For agentic workers:** Use `subagent-driven-development` and `AGENTS.md`. This is one top-level packet, **M1-CORE**, with one orchestrator and one ledger. Linked briefs are stages, not new user launches.

**Goal:** Complete M1: select one Skyrim SE installation, import two local ZIPs, reorder and preview the winning loose files, deploy by journaled copy, and Restore from both CLI and desktop. Prove failure/restart behavior on the named native targets.

**Architecture:** Both clients call one Rust service. Archive and resolver work is independent of native placement. SQLite owns catalog and journal records; the platform adapter owns handles, bounded lookup and filesystem effects. Prove each native write seam before wiring it into that service.

**Tech stack:** Rust `stable`, Cargo locked dependencies, SQLite, Tauri 2, React/TypeScript/Vite, npm and Node 24 LTS.

**Spec:** [M1 catalog and C1 exit](2026-11-20-m1-working-core.md), the linked contracts in the stage briefs, and [architecture gates](../../architecture.md#decision-and-proof-register).

**Status:** `draft` pending approval of this whole packet and preflight. No need for another user approval between routine stages.
