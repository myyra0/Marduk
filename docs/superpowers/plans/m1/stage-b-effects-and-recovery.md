# M1 Stage B — Native effects, copy and recovery

Part of [M1-CORE](../2026-11-21-m1-complete.md). Checkpoint B separates effects proved on a named native configuration from effects modeled in deterministic tests. Do not wire a fake, unqualified native primitive or optimistic fallback into a product build.

## Native effects and durable library (Task 5)

**Owners:** Sol for proof cases, platform contract and gate; DeepSeek for harness and verified adapter implementation. **Files:** `crates/platform/{src/lib.rs,src/library_stage.rs,tests/native_publication.rs}`, OS modules from Task 4, and `tests/platform/m1/native-publication/` for harness and evidence recipes. `docs/research/m1-native-results.md` owns the dated outcome table. `crates/core/src/import.rs` and `crates/storage/src/library.rs` may change only to connect the frozen stage contract. No deployment adapter in this task.

- [ ] Freeze the available configuration and effects from the [R03 runbook](../../../contracts/m1-native-proof.md): create without clobber; replace while retaining actually displaced bytes; checked detach; file and namespace barriers; private payload publication; Btrfs rename domain. Record exact environment, normal privileges, native error/outcome and pre/post object identity. The probe must prove ordinary synthetic file operations only; no game, external root, elevated operation, disk setup, or power cut on this launch.
- [ ] Build independent scratch witnesses for the runbook. Use explicit child checkpoints for concurrent modification, record the actual displaced bytes and target state, and independently read sentinels. A sharing refusal is evidence only for that exact refusal. A reported native error after a change may not be collapsed to “no effect.” Missing native portability evidence blocks the corresponding configuration; don't invent a widened fallback or consider another filesystem equivalent.
- [ ] Sol reviews the outcome table and freezes the native effect port: observed absence/regular/unavailable, no-clobber publication, replacement with retained displaced file, detach with retained displaced file, and file/namespace barrier results. Specify what remains observable after ambiguous failures, what evidence admits `durable`, and which configurations may consume each method. This primitive contract gate precedes native R02; integrated process and VM proof remain Task 8.
- [ ] Where the private-library boundary is proven, wire verified writer ownership, private archive snapshot, bounded streaming, immutable staged payload and checked namespace evidence into Task 3's receipt seam. Bind the reviewed import ID to those exact bytes; Apply does not reopen the selected ZIP path. Reobserve before publishing/discarding. A missing barrier or changed payload must not let the catalog commit a visible revision; a lost reply after SQL commit must not publish again.
- [ ] Run `cargo test --locked -p marduk-platform --test native_publication` with the explicit scratch configuration and `cargo test --locked -p marduk-storage --test library_contract` with native staging only where qualified. Report which scenarios ran and which were not run. Archive/test-only catalog work is still usable if native staging cannot be connected.

## Copy operations and recovery (Task 6)

**Owners:** Sol freezes contract/oracle; DeepSeek implements; fresh DeepSeek task reviewer and Sol review of the effect boundary. **Files:** `crates/core/{src/deployment.rs,src/recovery.rs,src/lib.rs,tests/recovery.rs}`, `crates/storage/{src/lib.rs,src/operation_journal.rs,migrations/0002_operations.sql,tests/operation_journal.rs}`, `crates/platform/{src/lib.rs,src/physical_copy.rs,tests/physical_copy.rs}`. Do not edit C01's frozen oracle or broaden the catalog schema beyond the shared intent references.

- [ ] Freeze the [R02 interfaces and lifecycle](../../../contracts/m1-recovery.md#ownership-and-stable-types). The root lease binds exact captured installation/Data identity across clients. Compile-time ports cover durable intent/generation state and the checked native effects; the core sees stable outcomes, not OS errors. Target refs and stage/backup refs are typed and operation-owned. Preserve original pre-image, current step pre-image and actually displaced bytes as distinct claims.
- [ ] Author and freeze all [nine recovery witnesses](../../../contracts/m1-recovery.md#planner-witnesses-and-gates) and journal integration checks. Use a fake with separate visible and durable states; model lost writes/ACKs, unavailable root, corrupt/missing pre-image, and idempotent resume without assuming SQLite and files commit together. Record the exact injected cut, independent resulting bytes/metadata references, active-generation state and effect count after repeat. Include cancellation before public mutation and a root lease conflict.
- [ ] Implement preview, apply, status, Restore and pending recovery. Validate all targets before effects; unknown original or missing parent fails without earlier writes. Persist backups/absence and validated ordered intents before first mutation. Replay previously claimed IDs before stale/current-generation checks. Roll back unfinished Deploy, continue unfinished Restore, and preserve external edits and prior backup on conflict. Do not infer ownership from a matching name, identical bytes or missing ACK.
- [ ] Connect SQLite journal and test it with separate connections/restarts. Enable real checked native effect wiring only with Task 5's reviewed outcomes and precise capability checks. Keep real-install writes unavailable until Task 8 and explicit authorization; a synthetic harness can exercise the real adapter against a fresh fixture root. Leave unqualified effects disconnected, not silently routed to an unchecked writer or an always-success fake.
- [ ] Run `cargo test --locked -p marduk-core --test recovery`, `cargo test --locked -p marduk-storage --test operation_journal`, and, where qualified, `cargo test --locked -p marduk-platform --test physical_copy`; run workspace checks. On fake-only results, label mechanism and remaining native dependency explicitly.

**Checkpoint B:** ledger links primitive proof by OS/filesystem, deterministic results, whether actual native wiring exists, and the exact unavailable cases. A failed primitive or missing environment does not require shelving the journal, DTOs or UI; no simulated success satisfies the native gate.
