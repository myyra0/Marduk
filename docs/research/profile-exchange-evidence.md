# Profile exchange and Collection publication

Source audit at the [pinned baseline](../inventory.md); paths below are relative to `src/`. Retain the outcomes, not the old manager's formats or state compatibility. A file, share code, draft revision and published revision are different outputs. The checks are proposed, not frozen.

## Local export and share

| Route | Source effect and proposed witness |
|---|---|
| Save or load export settings (M3-P03/M4-S02) | `gui_qt/profiles/export.py:1725–1759` saves the export table's choices as a profile-local settings file; Load applies saved choices to the current export rows, optionally preserving pins. It does not install mods, change membership, or produce an archive. `export_settings_round_trip_only_changes_the_draft`: missing row, new provider revision, canceled load, repeated save, and different profile with the same displayed name. |
| Profile archive export (M3-P03/M4-D01) | `gui_qt/profiles/export.py:1762–1838,1840–1878,1921–2012,2052–2080` rejects unresolved Nexus file selections, confirms bundling provider bytes for personal backup, and offers archive preflight and optional save-location selection before packaging. Preflight snapshots earlier than the packer; the late size update is by row index, then snapshots the table for packaging. Local edit patches can produce warnings; the UI logs them and still writes the archive. `Utils/profiles/export.py:830–926,929–1029,1032–1060` enumerates manifest, owned bundle/Overwrite/profile assets, optional saves and patches, guards colliding member names and checks file identity again before replacing the output with the flushed temporary archive. It strips selected group/host state but that is not a comprehensive portable-state or privacy allowlist. `archive_export_reviews_exact_rows_roots_and_bytes`: changed rows, owner or destination after review, missing patch, canceled save selection, unmanaged file and late cancellation. Report omissions, personal-only vs redistributable content, and package commit separately. |
| Local share code (M3-P03/M4-S01) | `gui_qt/app.py:13269–13371` builds from the game's active profile as read by the worker and returns code plus mod count; the completion carries no originating scope. It opens a copy overlay, not a remote write. Import always enters preview, including prefilled input. The code carries exact downloadable identities and installer decisions, not local bundle payloads (`Utils/profiles/export.py:1243–1259,1262–1335`). `share_code_is_scope_bound_and_reports_nonportable_rows`: profile switches before read or display, unmatched local content, two provider namespaces, and copied text vs explicit remote share. No apply from paste or preview. |

## Local import after the picker

- **Review and dispatch (M3-P03/M4-S01):** `gui_qt/app.py:13188–13266,13335–13371` gates Nexus access on the parsed source set and opens a review keyed by source stem, so two same-stem files can focus the same tab without replacing its input. File imports use a new-profile recommendation; code import enables append because it has no bundle. `gui_qt/collections/detail.py:145–207,1257–1316` binds the local manifest, selected optionals and Install intent. `gui_qt/app.py:6941–7037` passes the parsed manifest into the pipeline, holds Download-only constant and checks a version warning separately. `import_review_cannot_reuse_same_stem_or_unreviewed_target`: two files with the same stem, stale domains, optional-file skips, fully bundled offline import, code append, and toggled Download-only. Exact artifact and target generation, not tab name, identify review.
- **Bundle restoration is a second write phase (M3-P03/M3-X03/M4-S01/D01):** `Utils/profiles/export.py:1066–1090,1093–1171,1173–1237` recognizes a bare manifest or ZIP content, then plans the bundle's mod, Overwrite and profile writes, rejects colliding destinations/links and extracts into the target. Extraction and profile overlay are sequential, not one atomic publish. It preserves an authored order snapshot before reconciling absent rows (such as off-site content). `gui_qt/app.py:8319–8353,8384–8455,8457–8504` skips all bundle restoration in Download-only, otherwise reopens the ZIP after provider installs, restores selected collection bookkeeping, checks required folders and persists incomplete state. The non-group UI can still issue a success notice even with a bundle error; the separate saves offer is suppressed on error. `partial_bundle_is_not_ready_and_does_not_apply_saves`: swapped input after preview, bundle write failure between roots, missing required mod, disappeared off-site row, saved authored order and optional saves. Validate the reviewed package at Apply and don't hide partial publish behind a completed mod count or auto-deploy. Preserve separate restore and resume.
- **Repository import and gated config copy (M3-S03/M4-S01):** `Thunderstore/r2_profile.py:85–165,236–280`, `gui_qt/collections/detail.py:233–259,600–604,836–857` separate manifest parsing, exact repository/community/version lookup, omitted-entry acknowledgement and new isolated profile selection. `Thunderstore/r2_archive.py:21–70,73–131` bounds members and size, separates admitted config from skipped members, reopens and verifies the reviewed archive signature, then stages and writes config per file under `Root_Folder`; stopping during the final loop can leave committed files. `gui_qt/app.py:7495–7521,7723–7779` rechecks game/community, installs repository entries in a separate pass, and only restores config outside Download-only and before the generic pipeline's final result. Config failures and acknowledged omissions flow into incomplete status, not success. `repository_profile_import_separates_version_pins_configs_and_results`: wrong community, missing version, shared-profile target, changed bundle, skipped executable and cancellation before and during publication. Do not treat parsing as consent to write or a config extension as proof of safe content.

## Collection package, remote draft and publication

- **Local package (M4-S02):** `gui_qt/collections/create.py:791–849,889–902,932–961` snapshots reviewed export rows at operation start and binds picker/cancel to the operation ID, runs archive preflight and requires acknowledgement of package warnings before packing. `Utils/collections/export.py:1766–1822` writes a sibling `.part` and replaces the `.7z` after the pack finishes; this is not upload or proof of a crash-durable output. `collection_export_does_not_upload_or_transfer_further_rights`: canceled warning, failed temporary output, same destination chosen twice, omitted archive and local-only redistribution restrictions.
- **Upload vs draft registration (M4-S02, G-EXT):** `gui_qt/collections/create.py:1047–1121,1123–1230` distinguishes explicit new collection from selected draft revision; it can use the prior profile upload record only when the target picker is empty, and a missing/discarded target can fall back to a new draft. A confirmed operation prepares a temporary package, transfers it, checks cancellation, registers the draft, then writes local receipt metadata. A transfer failure can retain prepared bytes for retry; a registration failure is not that same retry path. `Nexus/nexus_api.py:3547–3613,3975–3999` uses different transfer session paths above 100 MiB and can edit the existing title before creating its revision, so a failed revision request does not prove no remote effect. `draft_upload_reconciles_exact_account_target_and_effect`: stale/deleted target, title edit success plus revision failure, lost receipt, failed local record and reused package under another account. Review the exact remote target and each distinct effect; no retry on unknown registration.
- **Publish, edit and listing (M4-S02, G-EXT):** `gui_qt/collections/mine.py:42–97,615–674` chooses the exact draft revision and prompts listed/unlisted plus adult-content flag; ordinary metadata edit, changelog edit and changing listing of an existing collection are separate callbacks. `Nexus/nexus_api.py:3888–3903` sends revision ID and selected listing/adult flags. Unlisted publication is still publication, not a private draft. `publish_uses_the_reviewed_draft_not_the_current_selection`: replaced draft or account, rejected or uncertain mutation, separate metadata/listing edit and exact outcome readback. No provider eligibility, distribution rights or live write is established by this audit.
