Those paths do not auto-install the catalog.
- The `Localisation` path had **13** compiled `.qm` entries, with separate translation source and tooling. Retain localization and data-only refresh where applicable, not Qt artifacts. The save-path file requested under `Ludusavi/` was not present in the inspected root or accessible by exact path at that revision. Keep unavailable-remote vs cached/local save discovery separate; this is not proof that save-path refresh never shipped or that an origin switch is approved.
- Retain built-in behavior that happens to use the old host internally. Do not infer bundled behavior from a module's author or the fact it appears in a default store. Reopen classification if an actual package or first-run trace installs an extension by default. User-added sources, release-specific remote state and packaged startup have not been exhaustively inspected.
