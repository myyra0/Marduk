## Cross-platform behavior checks

Design audit only. Run shared offline witnesses on Linux and Windows first, then exercise the relevant native path from each **approved installed package**. Record OS/architecture, package and origin, relevant volume/grant, runtime/helper/provider capability and observed result. Mark a route as unproven until checked; use not-applicable only for a documented route that has no corresponding platform operation, not for missing evidence.
