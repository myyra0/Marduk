# Built-in game and tool coverage

**Evidence level:** Pinned-source inspection, not a live, packaged, or supported-platform run. [Inventory](../inventory.md) defines product scope and [reference surfaces](reference-surfaces.md) lists game-ID candidates and packaged wizard modules.

## Game registration

Applying the built-in loader's `Games/*/*.py` glob and exclusions to the pinned tree yields **71 scanned files**, all listed in their family Meson manifests. They contain **73 top-level classes**, one of which is an exception type, not a game handler; one scanned file contains only helper functions. Two files provide two game classes each: Fallout New Vegas/New California (GOG) and Kingdom Come: Deliverance II/original. Six classes inherit their names and IDs from definition data rather than overriding them: Hades, Hades II, No Man's Sky, Prey, RimWorld and Voices of the Void. This reconciles the **72 built-in handler class/ID candidates** separately from the 31 directory count. It does not prove the classes initialize successfully or report unique display names at runtime.

Static extraction of literal `WizardTool.dialog_class_path` references from handler sources and the 13 entries in `Utils/wizards/plugins.py`'s built-in data list accounts for all 65 keys. The empty-key route for external wizard extensions is excluded. The explicit BepInEx wizard exclusion is not a live built-in wizard obligation; BepInEx game/content support is still in scope.

Tool visibility is computed on open in `gui_qt/app.py:15906–15978` from the current game plus the built-in tool catalog. A tool can require a staged executable, matching winning DLL, a supported title/runtime or repository-supplied data definition. `Utils/wizards/plugins.py:369–418` also records tool launch handoff for a subset of executable names; direct launching must not bypass required setup. Built-in catalog rows for `Slime_Rancher`, `My_Summer_Car` and `NieR__Automata` attach to compatible data-only definitions; they are not three extra compiled-in handlers. Their exact live catalog availability remains an external verification item.
