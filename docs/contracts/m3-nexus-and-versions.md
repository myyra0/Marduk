A cancelled/superseded attempt cannot adopt newly returned credentials; if commit already won, report the actual outcome rather than false cancellation. |

Use a fake OAuth exchange, secure store and launcher in deterministic tests. Keep callback verification, deadline and cancellation on the same attempt; validate which authentication routes and API credentials Marduk is authorized to ship. Do not reuse the reference's application credentials. For legacy setups with no secure store, distinguish missing service, locked service and denied access. Keep the persisted-no-keyring parity decision open in [M4-S04's shared credential note](m4-other-providers.md#secure-storage-decision); never silently drop persistent sign-in or create a fallback file.

The [upstream review](../research/provider-upstream-review.md#nexus-mods--m3-s02) separates issuer discovery, app registration and authorized API scope. If approved for native OAuth, use an external browser, S256 PKCE and attempt-bound callback validation with an approved redirect route; the app holds no confidential client secret. Classify NXM invalid grant, expired grant, forbidden tier and missing file separately. A browser-resumable download is not a manager checkpoint. Collapse overlapping catalog refreshes inside the same game/query/account scope and respect the provider's reset information; rate-limit backoff must not turn an old observation into install authority.

### Desktop detail and exact file selection

- `gui_qt/nexus/browser.py:1577–1597,1746–1769` opens native detail in the existing browser, with separate installed-mod and installed-file indicators. `gui_qt/nexus/mod_detail.py:511–609,682–751` loads missing description and files independently, retains facts omitted by the detail response, groups files and exposes an exact row action. A failed description must not erase available files; a failed file query isn't an empty successful list. “Reinstall” or “Redownload” on a row depends on that exact file, not merely the mod.
- `gui_qt/nexus/browser.py:2328–2429,2538–2561` distinguishes entry-level acquisition from an explicit detail row. The entry-level path uses the grouped chooser (including multi-selection), and may skip it for a single candidate. `gui_qt/nexus/file_chooser.py:60–71,226–245,255–270` prefers named install categories but falls back to all listed files if none match; detail rows don't use this filter. Keep discoverability and valid explicit selections separate from recommendation. An unavailable provider object remains a typed result, never “pick newest instead.”
- `gui_qt/nexus/browser.py:2431–2479,2482–2519,2530–2536` binds a manual wait to a selected file, can reuse a previously downloaded candidate, and mirrors watch state to card and detail. `gui_qt/app.py:5640–5668` uses an exact file key for certain pending reinstall/version contexts, but cancels the browser watch by game/domain and mod, not file. Preserve the wait/cancel outcome; make cancellation file-specific so an unrelated file cannot steal the watch. Recheck authorized acquisition and originating game/profile for review and commit. An exact accepted NXM handoff and the watcher cannot both publish. An unproven disk candidate may be explicitly reviewed but matching filename alone must not trigger installation.
- `gui_qt/nexus/mod_detail.py:54–114,624–663` renders spoilers and asynchronous rich-description images (including animated GIFs), with external web links distinct from in-app actions. Keep passive content and explicit browser opening; don't give author content renderer privileges, unscoped fetch or access to provider credentials. Evaluate bounded public-image loading with approved source/redirect policy, unavailable-media feedback and stale-result rejection. Freeze the allowed media policy with G-EXT; if it would remove a supported visible route, raise that decision rather than silently declaring parity.

## Shared installed-version contract

- `inspect_mod_versions(instance, profile, member, source)` returns exact owning mod/revision, all affected profile references, distinct installed/recommended/selectable provider versions, and an observation token. Selecting a file or asking for **Quick Update** does not itself authorize replacement. A recommendation uses the provider's confirmed successor policy, not the highest display string. Update checks may refresh derived flags and requirement diagnostics but do not replace payload or mark stale/offline results up-to-date. Provider-specific mapping, including mod.io and package sources, is owned by their adapters.
- `preview_version_change` binds owner, all affected membership revisions, source object, exact archive identity when obtained, reviewed installer choices and dependency policy. Downloads can finish independently; apply rechecks the source/version/catalog and affected profiles under checked leases before publication. Keep stable membership identity, placement and enabled state; refresh affected plugin/routing state and surface persisted-vs-derived failure explicitly. Replace via existing immutable revision publication; never mutate the old payload and never infer users approved another profile or source. A publication that left uncertain state blocks dependent operations on that owner.
- `inspect_version_rollback` identifies the exact recorded previous revision; `preview_version_rollback`/Apply use its retained immutable revision and recorded decisions if intact, or explicitly prepared exact previous archive when needed. This is simpler than always reinstalling an archive. A missing previous artifact yields a precise recovery action, not a download of “latest.” Traced previous-version rollback routes cover Nexus/Thunderstore/Hexium; do not claim a mod.io rollback route from its version-selection support.
- `preview_quick_update` returns independent exact successor plans, skipped owners/reasons and per-item options. Apply can acquire in parallel through the shared queue; it commits one reviewed owner at a time in deterministic order. Download-only leaves all installed versions unchanged. Report verified downloaded, committed, failed and unstarted separately. Stop before new publications on rollback/recovery failure; earlier committed owners remain recorded.
