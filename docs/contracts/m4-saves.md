**Status:** Draft, not dispatchable. Save content is not mod-library content or deployment recovery evidence.

## Review and apply

- `list_save_locations` identifies configured native/prefix and applicable profile-local roots with source, availability and ownership. A missing or inaccessible root remains visible as such, without being created or adopted on read. Inventory emits exact file/folder entry IDs and revisions. Preview header, image or text with bounded observers; stale asynchronous previews never replace the current selection.
- `preview_save_change` binds export, import, copy, move or remove to exact game/profile, scoped save location and current identities/revisions. Import binds admitted ZIP identity, archive member names, game-specific patterns, affected existing saves, and reviewed replacement; move binds source and destination independently; export binds the approved output location and any replacement decision. Where upstream save-path data is missing, retain verified cached and local discovery; do not silently redirect to another user's, profile's or game's path.
- `apply_save_change` checks the exact plan under source/destination leases; stage new bytes privately, preserve confirmed old bytes, publish and verify before any source cleanup. Delete via recoverable owned staging/journal; never assume moving an entry to another filesystem is atomic. If source cleanup fails after verified target publication, keep the complete target and remaining source, report pending cleanup, and revalidate only that cleanup on retry. Never roll back the only complete copy or re-take an external file path by string. Confirm a partial batch per item; stop on unresolved recovery, even with continue selected.

Require full checked admission before selecting a new copy, and exercise unavailable refresh, invalid newer cache, same date and newer compatible data without losing the verified fallback.
