# Deferred features

Existing capabilities with a specific blocker or an outstanding proof requirement. This is **not an ideas list**. A deferred capability is still part of the parity target unless explicitly removed; it may land in a later milestone, but cannot be left until after a full-parity release. An ordinary later milestone is not itself a deferral. The [inventory](inventory.md) and execution plan own status and acceptance evidence. Optional ideas not planned for the rewrite go in the [improvement backlog](backlog-improvements.md).
